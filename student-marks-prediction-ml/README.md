# Student Marks Prediction Using Machine Learning

## Project Overview:

##### This is a beginner-level Machine Learning project that predicts student marks based on the number of hours they study.

##### The project uses Linear Regression to learn the relationship between study hours and marks.



### Technologies Used:

##### \* Python

##### \* Pandas

##### \* NumPy

##### \* Matplotlib

##### \* Scikit-learn



### Machine Learning Algorithm:

#### Linear Regression

##### Linear Regression is a supervised Machine Learning algorithm that learns the relationship between input features and a target variable.

##### In this project:

##### \* Input feature: Study Hours

##### \* Target variable: Student Marks

### 

### Features:

##### \* Creates a dataset using Pandas.

##### \* Visualizes the relationship between study hours and marks.

##### \* Splits the dataset into training and testing sets.

##### \* Trains a Linear Regression model.

##### \* Predicts student marks based on study hours.

##### \* Evaluates the model using Mean Absolute Error (MAE).

##### \* Accepts study hours from the user.





### Project Structure:

##### student-marks-prediction-ml/

##### ├── main.py

##### ├── README.md

##### ├── requirements.txt





### Installation:

##### 1\. Install Python on your computer.

##### 2\. Clone this repository or download the project files.

##### 3\. Open a terminal in the project folder.

##### 4\. Install the required libraries:

##### pip install -r requirements.txt





### How to Run:

#### Run the following command in your terminal:

##### python main.py

##### Enter the number of study hours when prompted to receive a predicted marks value.



### Model Evaluation:

##### The model's performance is evaluated using Mean Absolute Error (MAE).

##### MAE measures the average absolute difference between the actual marks and the predicted marks in the testing dataset.

##### The evaluation result is displayed when the program runs.



### Dataset:

##### The project uses a small, manually created dataset containing study hours and corresponding marks.

##### This dataset is intended for learning and demonstration purposes.
